# fs25-vehicle-xml-reference

Справочник по XML техники и оборудования **Farming Simulator 25**: `modDesc` и все XML-блоки с
примерами. Только разметка (XML), без скриптинга.

Сайт: <https://deliciousnesquik.github.io/fs25-vehicle-xml-reference/>

## Что это

Постраничное описание блоков vehicle-XML FS25: назначение, каждый атрибут (тип, значение по
умолчанию, описание), под-элементы, примеры XML, устройство объекта в GIANTS Editor и типичные
ошибки. Источник схем — исходный код игры (базовые специализации `Vehicle.lua` и др.).

Навигация повторяет то, что правит человек: сначала **файл** (`modDesc.xml` или `vehicle.xml`),
внутри — группы блоков по назначению. Кто знает имя тега, но не раздел, идёт в
[указатель тегов A→Z](src/content/docs/start/tag-index.md); нотацию таблиц объясняет
[«Как читать справочник»](src/content/docs/start/how-to-read.md).

## Локальная сборка

Нужен Node **22.12+** (требование Astro 7).

```bash
npm install
npm run dev                 # http://localhost:4321/fs25-vehicle-xml-reference/
npm run build               # сборка в dist/
npm run preview             # посмотреть собранный сайт (поиск работает только здесь)
```

Поиск работает в продакшен-сборке: индекс Pagefind создаётся на этапе `build`, в `dev` его нет.

Публикация автоматическая: `.github/workflows/deploy.yml` собирает и выкладывает на GitHub Pages при
каждом пуше в `main`.

## Структура репозитория

```
src/content/docs/
├── index.mdx          — посадочная страница
├── start/             — как читать справочник, указатель тегов A→Z
├── mod-desc/          — элементы modDesc.xml
├── base/              — общие блоки любой техники
├── specializations/   — блоки по спецификациям
├── concepts/          — механизмы движка (наследование, CDATA, конфигурации)
├── recipes/           — задачи целиком (локализация, свой тип техники, покраска)
└── _template.md       — шаблон новой страницы (в сайт не попадает)

astro.config.mjs       — дерево навигации, локали, редиректы
src/plugins/           — remark-плагин: ссылки на .md → URL страниц
```

Каталоги — это URL, а группировка в дереве задаётся отдельно в `astro.config.mjs`. Поэтому страницу
можно перевесить в другую ветку дерева, не меняя её адрес.

## Как добавить страницу

1. Скопировать `src/content/docs/_template.md` в нужный каталог.
2. Заполнить frontmatter: `title` (заголовок страницы), `description` (одна строка — идёт в поиск и
   мета-описание), `sidebar.label` (короткое имя тега для дерева).
3. Добавить slug страницы в `sidebar` в `astro.config.mjs` — иначе страница откроется по ссылке, но
   в дереве её не будет. Неизвестный slug в `sidebar` роняет сборку: опечатку видно сразу.
4. Если добавили новый тег — дописать строку в `src/content/docs/start/tag-index.md`.

Ссылки между страницами пишутся относительными путями с расширением `.md`
(`../mod-desc/l10n.md`) — так они работают и на сайте, и при чтении файлов на GitHub. При сборке они
превращаются в URL; ссылка на несуществующий файл **роняет сборку**.

## Языки

Русский — основной язык (лежит в корне URL). Переключатель языка в шапке; страницы, для которых
перевода ещё нет, показываются по-русски. Перевод — файл по тому же пути в
`src/content/docs/en/` (например `src/content/docs/en/mod-desc/l10n.md`).

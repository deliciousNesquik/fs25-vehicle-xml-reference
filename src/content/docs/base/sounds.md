Ссылка на внешний (общий) XML-файл звуков техники.

Источник схемы: `Vehicle.lua` (`FS25`), `vehicle.base.sounds`.

> Здесь описан только **механизм ссылки** на файл звуков. Содержимое самого файла
> звуков (моторные, рабочие, звуки инструмента и т.д.) описывается отдельно.

---

## 1. Что это

`<sounds>` позволяет вынести определения звуков техники в **отдельный XML-файл** и подключить его по ссылке. Удобно для переиспользования одного набора звуков несколькими машинами или для использования общих звуков игры.

Схема:

```
vehicle.base.sounds#filename     — STRING, путь к внешнему файлу звуков
vehicle.base.sounds#volumeFactor — FLOAT, множитель громкости ко ВСЕМ звукам техники
```

Чтение (`Vehicle:loadFinished`): при наличии `#filename` файл грузится как отдельный `XMLFile` и проверяется по под-схеме звуков (корневой узел `sounds`). Элемент необязателен.

---

## 2. Атрибуты

| Атрибут | Тип | По умолчанию | Описание |
|---|---|---|---|
| `filename` | STRING | — | Путь к внешнему файлу звуков. |
| `volumeFactor` | FLOAT | — | Множитель, применяемый ко всем звукам этой техники. |

---

## 3. Разрешение пути

- **Относительно каталога мода**: `sounds/deutz_agrostar_661_sounds.xml`.
- **Из данных игры** через префикс `$data/...` — так подключают общие (shared) звуки базовой игры.

---

## 4. Примеры XML

Свой файл звуков в моде:

```xml
<base>
    <sounds filename="sounds/deutz_agrostar_661_sounds.xml"/>
</base>
```

С понижением общей громкости:

```xml
<base>
    <sounds filename="sounds/deutz_agrostar_661_sounds.xml" volumeFactor="0.85"/>
</base>
```

Переиспользование общих звуков игры:

```xml
<base>
    <sounds filename="$data/vehicles/sounds/.../shared_sounds.xml"/>
</base>
```

---

## 5. Примечания

- Внешний файл звуков имеет собственный корневой узел `<sounds>` и свою схему — его наполнение вынесено в отдельную страницу справочника.
- Без `<sounds>` звуки берутся из секций звуков внутри самого vehicle-XML (если они там определены).

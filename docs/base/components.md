# Farming Simulator 2025
## Блок `<components>` в XML техники/оборудования

Руководство описывает настройку компонентов техники и оборудования в движке `GIANTS Engine`[^giantsengine] версии **10** для реалистичной физики: назначение каждого параметра (атрибута), а также случаи, когда компоненты применять следует, а когда — нет.

Источник схемы: `Vehicle.registerComponentXMLPaths` + `loadComponentFromXML` /
`loadComponentJointFromXML` (базовый `Vehicle.lua` `FS25`). Все атрибуты и значения по умолчанию — из исходного кода.

> Схема регистрируется одинаково для `vehicle.base.components` и для
> `vehicle.base.componentConfigurations.componentConfiguration(?)` (конфигурации).

---

## 1. Что такое компонент

**Компонент** — отдельное физическое твёрдое тело[^rigidbody] (rigid body) техники. Движок рассчитывает для него физику: **массу**, **инерцию**[^inertia], **столкновения**, **положение**.

- Если у техники **несколько компонентов**, они соединяются **шарнирами**[^joint] (joint) и могут двигаться друг относительно друга по физике: поворот дышла (сцепного бруса), ход подвески, складывание секции на петле.
- Если техника — **одно тело**, у неё один компонент, а внутренние части движутся не физикой, а анимацией либо `movingTools` (гидроцилиндры).

Компоненты берутся из **i3d**[^i3d]: верхнеуровневые дочерние ноды[^node] (узлы сцены) корня техники с назначенным типом физики (`RigidBodyType`[^rigidbodytype]). XML лишь настраивает их параметры.

## 2. Контейнер `<components>` — атрибуты

| Атрибут | Тип | По умолчанию | Описание |
|---|---|---|---|
| `numComponents` | INT | реальное число нод в i3d | Число загружаемых компонентов. Обычно не указывается — берётся из i3d. |
| `maxMass` | FLOAT (кг) | без ограничения | Максимальная суммарная масса техники. Внутри движка делится на 1000 (тонны). |
| `directionReferenceNode` | node | — | Нода для расчёта текущего направления и скорости движения. |

```xml
<components maxMass="18000">
    <component index="1" mass="4200"/>
    <component index="2" mass="1500"/>
    <joint component1="1" component2="2" node="jointDrawbar" rotLimit="0 25 0" transLimit="0 0 0"/>
    <collisionPair component1="1" component2="2" enabled="false"/>
</components>
```

## 3. `<component>` — атрибуты

| Атрибут | Тип | По умолчанию | Описание |
|---|---|---|---|
| `index` | INT | порядковый номер в списке | Нода i3d, к которой привязан компонент. По умолчанию N-й `<component>` соответствует N-й верхнеуровневой ноде корня; `index` переопределяет это соответствие. |
| `mass` | FLOAT (кг) | из i3d; при полном отсутствии — **500 кг** (с предупреждением) | Масса тела. Значение меньше 10 вызывает предупреждение (вероятно, масса указана в тоннах вместо килограммов). |
| `centerOfMass` | x y z | из i3d (не `0 0 0`) | Центр масс[^com] в локальных координатах. Смещение вниз повышает устойчивость (снижает вероятность опрокидывания). |
| `inertiaScale` | x y z | `1 1 1` | Масштаб инерции[^inertia] (распределения массы) по осям. Большее значение — большее сопротивление вращению. Инерция растёт квадратично от радиуса (значение 4 соответствует объекту вдвое большего размера вдоль оси). |
| `solverIterationCount` | INT | значение движка (если не задан — не изменяется) | Число итераций решателя[^solver] физики для тела. Большее значение — устойчивее соединения, но выше нагрузка на процессор. Для сложных сцепок 20–40. |
| `motorized` | BOOL | задаётся спецификацией мотора | Признак моторизованного компонента (для самоходной техники). Обычно задаётся автоматически. |
| `collideWithAttachables` | BOOL | `false` | Сталкивается ли компонент с навесным оборудованием. |

**Важно:** в XML отсутствуют `collisionMask`, `angularDamping`/`linearDamping`,
`restingAllowed`, `wakeUpTimer`. Демпфирование[^damping] (гашение колебаний) и режим
покоя тела задаются **на ноде в GIANTS Editor**[^giantseditor]; XML их только проверяет и
выдаёт предупреждение (ненулевой linear damping, angular damping вне диапазона 0.0001–0.05).

Пример — компонент с ручной массой, центром масс и увеличенной устойчивостью вращения:

```xml
<component index="1" mass="1500" centerOfMass="0 0.2 0" solverIterationCount="15"/>
```

Пример — вытянутое тело (рама), инерция увеличена вдоль продольной оси Z:

```xml
<component index="1" mass="3200" centerOfMass="0 0.1 0" inertiaScale="1 1 3"/>
```

## 4. `<joint>` — шарнир между компонентами

Соединяет два компонента. Атрибуты сгруппированы по назначению.

### 4.1 Что соединяем

| Атрибут | Тип | По умолчанию | Описание |
|---|---|---|---|
| `component1` | INT | обязателен | Первый компонент (нумерация с 1). |
| `component2` | INT | обязателен | Второй компонент. |
| `node` | node | обязателен (≠0) | Нода-шарнир (точка и ориентация осей соединения) на компоненте 1. При отсутствии шарнир не создаётся. |
| `nodeActor1` | node | = `node` | Ответная нода-якорь на компоненте 2. |
| `initComponentPosition` | BOOL | `true` | Смещать и поворачивать компонент 2 при загрузке для совмещения с шарниром. |

### 4.2 Лимиты (диапазон движения)

| Атрибут | Тип | По умолчанию | Единицы | Описание |
|---|---|---|---|---|
| `rotLimit` | x y z | `0 0 0` | градусы | Максимальный поворот по каждой оси. **0 = ось заблокирована.** |
| `transLimit` | x y z | `0 0 0` | метры | Максимальный сдвиг по каждой оси. **0 = ось заблокирована.** |
| `rotMinLimit` | x y z | `-rotLimit` | градусы | Минимальный поворот (по умолчанию симметрично `-rotLimit`). |
| `transMinLimit` | x y z | `-transLimit` | метры | Минимальный сдвиг. |

Интерпретация:
- `rotLimit="0 0 0" transLimit="0 0 0"` — жёсткое соединение (тела скреплены неподвижно). Основной случай для многосоставной рамы.
- `rotLimit="0 30 0"` — поворот по оси Y в диапазоне ±30° (минимум по умолчанию `-30`).

Жёсткое соединение и поворотное дышло (рыскание — поворот вокруг вертикали):

```xml
<!-- жёсткое соединение двух частей рамы -->
<joint component1="1" component2="2" node="jointMiddle" rotLimit="0 0 0" transLimit="0 0 0"/>

<!-- поворотное дышло: только рыскание по Y в диапазоне +-25 градусов -->
<joint component1="1" component2="2" node="jointDrawbar" rotLimit="0 25 0" transLimit="0 0 0"/>
```

**Особый случай — свободная ось.** Отрицательный максимум без указанного минимума даёт
минимум больше максимума, и движок оставляет ось без ограничения. Применяется для
свободного вращения оси или колеса:

```xml
<!-- свободное вращение вокруг локальной оси X (например, ось колеса) -->
<joint component1="2" component2="3" node="jointAxle" rotLimit="-1 0 0" transLimit="0 0 0"/>
```

### 4.3 Пружина и демпфер лимита (подвеска)

| Атрибут | Тип | По умолчанию | Описание |
|---|---|---|---|
| `rotLimitSpring` | x y z | `0 0 0` | Жёсткость пружины на границе поворота. |
| `rotLimitDamping` | x y z | `1 1 1` | Демпфирование[^damping] (гашение колебаний) поворота. |
| `transLimitSpring` | x y z | `0 0 0` | Пружина на границе сдвига (упругая подвеска по оси). |
| `transLimitDamping` | x y z | `1 1 1` | Демпфирование сдвига. |
| `rotLimitForceLimit` | x y z | `-1 -1 -1` | Предельная сила удержания поворота (−1 — без ограничения). |
| `transLimitForceLimit` | x y z | `-1 -1 -1` | То же для сдвига. |

Пример — упругая вертикальная подвеска: тело может ходить по оси Y в пределах ±0.1 м, с пружиной и демпфером:

```xml
<joint component1="1" component2="2" node="jointAxle"
       rotLimit="0 0 0"
       transLimit="0 0.1 0"
       transLimitSpring="0 60 0"
       transLimitDamping="0 8 0"/>
```

### 4.4 Привод шарнира (моторизованный сустав)

Привод активируется, только если соответствующая максимальная сила
(`maxRotDriveForce` / `maxTransDriveForce`) больше 0 и задана цель (скорость,
поворот или позиция).

| Атрибут | Тип | По умолчанию | Единицы | Описание |
|---|---|---|---|---|
| `maxRotDriveForce` | x y z | `0 0 0` | сила | Максимальная сила поворотного привода. |
| `rotDriveVelocity` | x y z | — | град/с | Целевая угловая скорость. |
| `rotDriveRotation` | x y z | — | градусы | Целевой угол поворота. |
| `rotDriveSpring` / `rotDriveDamping` | x y z | `0 0 0` / `0 0 0` | — | Пружина и демпфер поворотного привода. |
| `maxTransDriveForce` | x y z | `0 0 0` | сила | Максимальная сила линейного привода. |
| `transDriveVelocity` | x y z | — | м/с | Целевая линейная скорость. |
| `transDrivePosition` | x y z | — | метры | Целевая позиция. |
| `transDriveSpring` / `transDriveDamping` | x y z | `0 0 0` / `1 1 1` | — | Пружина и демпфер линейного привода. |
| `zRotationNode` | node | — | — | Смещение оси Z-вращения (только по локальной оси X). |

Пример — поворотный привод, удерживающий заданный угол по оси Y с ограниченной силой:

```xml
<joint component1="1" component2="2" node="jointSteer"
       rotLimit="0 45 0"
       maxRotDriveForce="0 5000 0"
       rotDriveRotation="0 0 0"
       rotDriveSpring="0 400 0"
       rotDriveDamping="0 40 0"/>
```

### 4.5 Разрушение и столкновения

| Атрибут | Тип | По умолчанию | Описание |
|---|---|---|---|
| `breakable` | BOOL | `false` | Может ли шарнир разрушиться при перегрузке. |
| `breakForce` | FLOAT | `10` | Сила разрушения (при `breakable="true"`). |
| `breakTorque` | FLOAT | `10` | Момент разрушения. |
| `enableCollision` | BOOL | `false` | Учитывать ли столкновение этих двух компонентов между собой. Как правило, `false`. |

Пример — разрушаемое соединение:

```xml
<joint component1="1" component2="2" node="jointHitch"
       rotLimit="0 0 0" transLimit="0 0 0"
       breakable="true" breakForce="150" breakTorque="150"/>
```

## 5. `<collisionPair>` — отключение столкновений между компонентами

| Атрибут | Тип | Описание |
|---|---|---|
| `component1` | INT | Первый компонент (с 1). |
| `component2` | INT | Второй компонент. |
| `enabled` | BOOL | `false` — отключить столкновение этой пары. |

Применяется, когда коллизии двух компонентов пересекаются в пространстве (например,
колесо частично внутри крыла): иначе движок будет их расталкивать, и части теряют
соединение. На практике элемент используют именно для **отключения** пар.

```xml
<!-- отключить столкновение основной рамы (1) и крыла (3) -->
<collisionPair component1="1" component2="3" enabled="false"/>
```

## 6. Устройство объекта в GIANTS Editor 10

Соответствие XML и i3d:

1. **Корень техники** — верхняя нода (индекс `0`, в путях `0>`).
2. **Компоненты — верхнеуровневые дочерние ноды корня.** Каждый компонент — отдельная
   transform-нода (узел трансформации) под корнем. N-й `<component>` соответствует N-й
   такой ноде (или ноде, заданной атрибутом `index`).
3. **Настройка каждой ноды-компонента:**
   - `RigidBodyType`[^rigidbodytype] `= Dynamic` (подвижное тело; масса применяется только к Dynamic). `Static`/`Kinematic` — для неподвижного.
   - имя должно содержать `_component` (соглашение; иначе предупреждение), например `component1`, `wheel_component2`.
   - установить `Collision Mask`/`Group` с битом `VEHICLE` (иначе предупреждение и некорректные столкновения).
   - под компонентом — дочерние коллизионные меши (с нужной маской) и визуальные модели.
4. **Компонент 1 — главный (корневой):** задаёт точку отсчёта (origin) техники. Его
   Y-координата обязана быть 0 (иначе предупреждение). Он также используется как нода
   рулевой оси по умолчанию и хранит неиспользуемые ноды.
5. **Ноды шарниров** — пустые transform-группы, размещённые точно в точке шарнира. Их
   ориентация задаёт оси для `rotLimit`/`transLimit`. Смещённая нода создаёт большое
   плечо силы и вызывает нестабильность.
6. **Масса, центр масс, демпфирование, число итераций решателя** задаются на ноде в
   GIANTS Editor; массу и центр масс можно переопределить в XML.

## 7. Когда компоненты нужны, а когда нет

Основное правило:

> Отдельный компонент требуется только если часть должна двигаться относительно других
> **по физике** (через шарнир). Если часть неподвижна или движется анимацией/гидроцилиндром,
> отдельный компонент не нужен.

**Компоненты применять следует:**
- Поворотное дышло (сцепной брус) или сцепка, движущаяся по физике.
- Подвеска: ось или тележка, качающаяся либо ходящая вертикально (шарнир с пружиной и демпфером).
- Поворотная тележка (dolly) относительно основной рамы.
- Складные секции на петлях, физически повторяющие рельеф (копирующие крылья).
- Сочленённая техника (переломная рама).

**Компоненты не требуются (типичные ошибки):**
- **Жёсткая рама из нескольких частей.** Соединять 5–7 компонентов шарнирами с
  `rotLimit=0 transLimit=0` нецелесообразно: это увеличивает нагрузку на решатель и
  вызывает нестабильность (части теряют соединение). Следует использовать одно тело
  (один компонент).
- **Складывание или движение только визуальное** — выполняется анимацией (`<animations>`),
  а не компонентами.
- **Гидроцилиндры и управляемые игроком узлы** — выполняются через `cylindered`
  (`movingTools`/`movingParts`), а не компонентами.
- **Навесной инструмент** (плуг, культиватор, опрыскиватель на трёхточечной навеске) —
  как правило, один компонент; поворот относительно трактора обеспечивает `attacherJoint`,
  а не разбиение на компоненты.

**Практический критерий:**
- Часть качается, катится или переламывается по физике — компонент и шарнир.
- Часть неподвижна или движется анимацией — оставить в существующем компоненте.
- Меньшее число компонентов повышает стабильность и снижает нагрузку на процессор.
  Разбиение применять только по необходимости.

## 8. Типичные ошибки (по предупреждениям загрузчика)

- **Y-координата компонента 1 не равна 0** — предупреждение, некорректная точка отсчёта. Установить компонент 1 в 0 по Y.
- **Масса меньше 10** — вероятно, значение указано в тоннах вместо килограммов.
- **Отсутствует бит `VEHICLE`** в маске или группе коллизии — некорректные столкновения.
- **Длинные жёсткие цепи компонентов при низком `solverIterationCount`** — соединения
  расходятся, части отсоединяются. Решение: уменьшить число компонентов и/или задать
  `solverIterationCount` 20–40.
- **Пересекающиеся коллизии компонентов** — расталкивание и отсоединение. Решение:
  `collisionPair ... enabled="false"` для пересекающихся пар.
- **Смещённая нода шарнира** (не в точке шарнира) — большое плечо силы, рывки.
- Демпфирование и режим покоя тела задаются не в XML, а на ноде в GIANTS Editor.

## 9. Полный пример

Прицеп из трёх компонентов: рама (1), поворотное дышло (2) и подрессоренная ось (3).
Столкновения между смежными компонентами отключены.

```xml
<components maxMass="16000">
    <component index="1" mass="3800" centerOfMass="0 0.3 0" solverIterationCount="20"/>
    <component index="2" mass="600"  centerOfMass="0 0 0"   solverIterationCount="20"/>
    <component index="3" mass="1200" centerOfMass="0 0 0"   solverIterationCount="20"/>

    <!-- дышло: рыскание по Y +-30 градусов -->
    <joint component1="1" component2="2" node="jointDrawbar"
           rotLimit="0 30 0" transLimit="0 0 0"/>

    <!-- ось: упругий вертикальный ход по Y +-0.08 м -->
    <joint component1="1" component2="3" node="jointAxle"
           rotLimit="0 0 0" transLimit="0 0.08 0"
           transLimitSpring="0 80 0" transLimitDamping="0 10 0"/>

    <collisionPair component1="1" component2="2" enabled="false"/>
    <collisionPair component1="1" component2="3" enabled="false"/>
</components>
```

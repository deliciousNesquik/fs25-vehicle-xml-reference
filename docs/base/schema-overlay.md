# Farming Simulator 2025
## Элемент `<schemaOverlay>` в блоке `<base>`

Силуэт техники в схеме навески (диаграмма машины и точек сцепки в интерфейсе).

Источник схемы: `Vehicle.lua` (`FS25`), `vehicle.base.schemaOverlay`.

---

## 1. Что это

`<schemaOverlay>` задаёт **схематичный значок (силуэт)** техники, который игра рисует в схеме навесного оборудования (HUD-диаграмма: что к чему прицеплено и где точки сцепки). Сам силуэт выбирается по имени из реестра силуэтов игры.

Загрузка (`Vehicle:loadFinished`): если элемент присутствует, создаётся объект схемы `VehicleSchemaOverlayData` с позициями и именем силуэта; имя силуэта префиксуется идентификатором мода, чтобы моды не конфликтовали с базовыми именами.

---

## 2. Атрибуты

| Атрибут | Тип | По умолчанию | Описание |
|---|---|---|---|
| `name` | STRING | `""` | Имя силуэта из реестра `$dataS/vehicleSchemaOverlays.xml`. |
| `attacherJointPosition` | VECTOR_2 (`"x y"`) | — | Положение точки сцепки в диаграмме. |
| `basePosition` | VECTOR_2 (`"x y"`) | = `attacherJointPosition` | Положение корпуса техники в диаграмме. |
| `invisibleBorderRight` | FLOAT | — | Невидимый отступ справа у изображения силуэта. |
| `invisibleBorderLeft` | FLOAT | — | Невидимый отступ слева. |

---

## 3. Значение `name`

`name` — имя из файла-реестра **`$dataS/vehicleSchemaOverlays.xml`** (на него в схеме указан источник автодополнения). Там перечислены именованные силуэты; мод может определить свои. Имя мода автоматически добавляется префиксом, чтобы кастомные силуэты не пересекались с базовыми.

### Стандартные значения `name`

| Значение | Класс техники |
|---|---|
| `VEHICLE` | обычная техника |
| `HARVESTER` | комбайн |
| `TRUCK` | грузовик |
| `CAR` | легковой автомобиль |
| `LOADER` | погрузчик / телехендлер |
| `IMPLEMENT` | навесной инструмент |
| `TRAILER` | прицеп |
| `COMBINE_HEADER` | жатка |
| `FRONTLOADER` | фронтальный погрузчик |

> Набор подтверждён по коду GIANTS (`VehicleSchemaOverlayData.lua`, FS22-зеркало); в FS25 подтверждён путь/атрибут (`$dataS/vehicleSchemaOverlays.xml`). Сам файл может содержать дополнительные имена — сверяйся с автодополнением в GIANTS Editor.

`attacherJointPosition` — координаты точки сцепки в 2D-диаграмме (не мировые координаты), `basePosition` — положение корпуса (по умолчанию совпадает с точкой сцепки).

---

## 4. Примеры XML

Простой случай (силуэт «техника», точка сцепки в центре):

```xml
<base>
    <schemaOverlay attacherJointPosition="0 0" name="VEHICLE"/>
</base>
```

С отдельным положением корпуса и отступами:

```xml
<base>
    <schemaOverlay name="IMPLEMENT"
                   attacherJointPosition="0 0"
                   basePosition="0.1 0"
                   invisibleBorderLeft="0.05"
                   invisibleBorderRight="0.05"/>
</base>
```

---

## 5. Примечания

- Конкретные допустимые имена силуэтов задаются данными игры (`$dataS/vehicleSchemaOverlays.xml`), а не жёстко в коде.
- Устаревшие формы FS17–FS22 (`#file`, `#width`, `#height`, под-элементы `default/turnedOn/selected`) заменены на единый `schemaOverlay#name`.

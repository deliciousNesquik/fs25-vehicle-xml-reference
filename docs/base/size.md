# Farming Simulator 2025
## Элемент `<size>` в блоке `<base>`

Габаритная «коробка» техники: занимаемые ширина, длина, высота и их смещения.

Источник схемы: `Vehicle.lua` (`FS25`) + `StoreItemUtil.lua`, `vehicle.base.size`.

---

## 1. Что это

`<size>` задаёт занимаемые габариты техники (в метрах) и их смещения относительно центра. Используется для отображения в магазине, для габарита ИИ-работника и для служебных расчётов (например точки проверки воды).

Схема:

```
vehicle.base.size#width        — FLOAT (обязателен)
vehicle.base.size#length       — FLOAT (обязателен)
vehicle.base.size#height       — FLOAT
vehicle.base.size#widthOffset  — FLOAT
vehicle.base.size#lengthOffset — FLOAT
vehicle.base.size#heightOffset — FLOAT
vehicle.base.size#yRotation    — ANGLE, по умолчанию 0
```

Чтение — через `StoreItemUtil.getSizeValuesFromXML` в `self.size`.

---

## 2. Атрибуты

| Атрибут | Тип | По умолчанию | Описание |
|---|---|---|---|
| `width` | FLOAT (м) | движковый `DEFAULT_SIZE` | Ширина габарита. |
| `length` | FLOAT (м) | движковый `DEFAULT_SIZE` | Длина габарита. |
| `height` | FLOAT (м) | движковый `DEFAULT_SIZE` | Высота габарита. |
| `widthOffset` | FLOAT (м) | 0 | Смещение габарита по ширине. |
| `lengthOffset` | FLOAT (м) | 0 | Смещение по длине (сдвиг «коробки» вперёд/назад). |
| `heightOffset` | FLOAT (м) | 0 | Смещение по высоте. |
| `yRotation` | ANGLE | 0 | Поворот габарита вокруг вертикали; используется для проверки направления работы ИИ. |

> Точные числовые значения `DEFAULT_SIZE` (запасные width/length/height) заданы в движке и в открытом Lua-срезе не приводятся; смещения по умолчанию — 0.

---

## 3. Для чего используется

- **Магазин** — размер предмета в карточке/предпросмотре (грузится отдельно для магазина).
- **ИИ-работник** — если у агента включён `useSize`, его габарит берётся из `self.size` (ширина/длина/высота + смещения); иначе запасная ширина 3 м.
- **Служебные расчёты** — например точки проверки воды считаются от `size.height`.
- **`yRotation`** — поправка направления при проверках работы ИИ.

Конфигурации техники могут переопределять размер (через обработчик размера конкретной конфигурации). При повороте предмета габарит и смещения пересчитываются шагами по 90°.

---

## 4. Примеры XML

Базовый габарит:

```xml
<base>
    <size width="3" length="5" height="3" lengthOffset="-0.1"/>
</base>
```

Со смещением по высоте и поворотом:

```xml
<base>
    <size width="2.6" length="8" height="3.5" lengthOffset="0.5" heightOffset="0.2" yRotation="0"/>
</base>
```

---

## 5. Примечания

- `width`/`length` помечены как обязательные — задавайте их явно.
- Смещения полезны, когда центр модели не совпадает с геометрическим центром габарита (например длинная навеска смещена назад).

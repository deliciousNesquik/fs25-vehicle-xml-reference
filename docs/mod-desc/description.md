# Farming Simulator 2025
## Элемент `<description>`

```xml
<description>
    <en><![CDATA[Full mod description on English.]]></en>
    <ru><![CDATA[Полное описание мода на русском.]]></ru>
</description>
```

Многоязычное описание мода — текст, который игрок видит на странице мода (магазин, детали).
Структура языков — такая же, как у `<title>`; длинный текст обычно оформляют через CDATA.

> Расположение: дочерний элемент `<modDesc>`. Раздел справочника — modDesc.

---

## 1. Что это

`<description>` содержит подробный текст о моде отдельно для каждого языка: назначение, завод/бренд,
характеристики, цена, список изменений, благодарности. Отображается на экране деталей мода.

---

## 2. Характеристики

| Свойство | Значение |
|---|---|
| Обязателен | нет по схеме (`minOccurs="0"`), но практически указывается всегда. |
| Кратность | один тег `<description>` (`maxOccurs="1"`). |
| Дочерние элементы | языковые коды (`<en>`, `<ru>`, …), каждый — строка[^string]. |
| Набор языков | закрытый: те же 27 кодов, что у `<title>` (см. страницу title). |
| `<en>` обязателен? | схемой — нет; фактически нужен как фолбэк. |
| Атрибуты | нет. |

---

## 3. Структура и языки

Дочерние теги — языковые коды из **того же закрытого набора 27 кодов**, что и у `<title>`
(`en, de, fr, ru, uk, pl, it, es, pt, br, nl, cz, hu, da, no, sv, fi, tr, ro, id, jp, kr, vi, cs,
ct, ea, fc`). Полный разбор кодов и соответствий — на странице [title](title.md). Тег вне набора
невалиден по схеме (ModHub отклонит, движок проигнорирует).

`<title>` и `<description>` в схеме описаны отдельно, но структура у них идентичная.

---

## 4. Содержимое: текст и CDATA

Значение каждого языкового тега — произвольный текст. Для описания он обычно длинный и
многострочный (характеристики, changelog), поэтому его оформляют в секции CDATA — так внутри можно
свободно писать `<`, `&`, `€`, кавычки и переносы строк без экранирования. Подробнее о механизме —
на странице [CDATA](../concepts/cdata.md).

Без CDATA спецсимволы придётся экранировать сущностями (`&lt;`, `&amp;` и т.п.).

---

## 5. Какой язык показывается (фолбэк)

Как и у `<title>`: игра берёт текст текущего языка; если его нет — фолбэк на `<en>`; если нет и
его — описание может оказаться пустым. Английский стоит указывать всегда. (Логика выбора языка —
поведение движка локализации, в схеме не описана.)

---

## 6. Примеры

Многострочное описание с характеристиками и списком изменений (CDATA):

```xml
<description>
    <en><![CDATA[
LDG-10
Manufacturer: BELAGROSELHOZ
Price: 21000 €
Working width: 10.0 m
Required power: 150 hp

Changelog 1.0.1:
Fixed spring physics
Fixed wheel positions
    ]]></en>
    <ru><![CDATA[
ЛДГ-10
Завод-производитель: БелАгроСельхозСнаб
Цена: 21000 €
Рабочая ширина: 10.0 м
Необходимая мощность: 150 л.с.

Список изменений 1.0.1:
Исправлена физика пружин
Исправлено положение колёс
    ]]></ru>
</description>
```

Короткое описание, только английский (сработает фолбэком для всех языков):

```xml
<description>
    <en><![CDATA[When a trailer tips over, part of its cargo spills out over time.]]></en>
</description>
```

---

## 7. Типичные ошибки

- **Неподдерживаемый языковой код** (`<ua>`, `<zh>`): невалидно по схеме, ModHub отклонит, движок игнорирует.
- **`]]>` внутри текста CDATA** — обрывает секцию (см. страницу CDATA).
- **Нет `<en>`** — для языков, которых нет в описании, текст не покажется.
- **Несколько тегов `<description>`** — допускается только один.

---

## 8. Примечания

- По схеме `<description>` необязателен, но описание практически всегда указывают.
- Структура языков совпадает с `<title>`; набор кодов закрытый (27).
- Для длинного/спецсимвольного текста используется CDATA (отдельная страница в разделе Concepts).

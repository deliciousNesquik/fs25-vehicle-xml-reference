# Farming Simulator 2025
## Элемент `<iconFilename>`

```xml
<iconFilename>icon.dds</iconFilename>
```

Путь к файлу иконки мода — картинки, которая показывается в списке/меню модов. Значение — путь
относительно корня мода. Формат иконки — DDS 512×512 (см. раздел 3).

> Расположение: дочерний элемент `<modDesc>`. Раздел справочника — modDesc.

---

## 1. Что это

`<iconFilename>` указывает, какой файл использовать как иконку **мода** (не товара в магазине).
Иконка видна игроку в перечне модов и в деталях мода.

---

## 2. Характеристики

| Свойство | Значение |
|---|---|
| Тип содержимого | путь к файлу (STRING[^string]), относительно корня мода. |
| Обязателен | да (`minOccurs="1"` в официальной схеме[^xsd]). |
| Кратность | один. |
| Атрибуты | нет. |
| Расширение | указывается в значении (`icon.dds`). |

---

## 3. Формат файла иконки мода

По гайдлайнам ModHub для иконки мода (modIcon):

| Свойство | Значение |
|---|---|
| Размер | 512×512 px |
| Формат | DDS[^dds] |
| Сжатие | BC1 (DXT1)[^bcn] |
| Мип-мапы[^mipmaps] | без |
| Фон | непрозрачный, шаблонный; объект по центру |

Иконка мода отличается от других иконок игры (не путать):

| Иконка | Файл | Сжатие | Фон |
|---|---|---|---|
| Мода (`<iconFilename>`) | `icon_*.dds` | BC1, без мипов | непрозрачный (шаблон) |
| Товара в магазине (storeItem) | `store_*.dds` | BC3/BC7, без мипов | прозрачный |
| Бренда (brand) | `brand_*.dds` (512×256) | BC3/BC7 | — |

Для иконки мода прозрачность не нужна — фон шаблонный, поэтому используется BC1 (без альфа-канала).

---

## 4. Путь и имя файла

- Значение — путь **относительно корня мода**, с расширением: `icon.dds`.
- Файл можно держать в подпапке и указывать путь к ней: `icons/icon.dds`.
- Гайдлайны ModHub рекомендуют имя вида `icon_<ИмяМода>.dds`; движок читает любой указанный путь,
  поэтому `icon.dds` тоже работает.

---

## 5. PNG вместо DDS

- Игра **загрузит** `.png`, но выдаст предупреждение о производительности (в логе — про
  отсутствие мип-мапов / «raw format»).
- Для публикации на ModHub `.png` **не подходит** — проверка отклонит мод. Для релиза всегда DDS.

---

## 6. Если файла нет

Если по указанному пути файла нет, в лог пишется `Error: Missing dds file '...'`, и мод
**грузится дальше без иконки** (пустое место вместо картинки). Отбраковки в игре не происходит,
но на ModHub такой мод проверку не пройдёт.

---

## 7. Как сделать иконку

- **Шаблон фона** FS25 (непрозрачный, 512×512): `https://www.farming-simulator.com/modHub/documents/FS25_ModHub_BG512.png` — на него ставят изображение техники по центру.
- **GIANTS Icon Generator** — рендерит иконку прямо из `.i3d` и сохраняет DDS в нужном формате (для мода без 3D-модели не нужен — иконку собирают вручную поверх шаблона).
- **Вручную** — графический редактор с поддержкой DDS (например с DDS-плагином) либо конвертер PNG→DDS; экспорт в BC1 (DXT1), 512×512, без мип-мапов.

---

## 8. Примеры

```xml
<iconFilename>icon.dds</iconFilename>
```

Иконка в подпапке:

```xml
<iconFilename>icons/icon_SpillOnRollover.dds</iconFilename>
```

---

## 9. Типичные ошибки

- **Файл отсутствует** по указанному пути — `Missing dds file` в логе, мод без иконки.
- **`.png` в релизе** — предупреждение и отказ на ModHub; нужен DDS.
- **Формат товара вместо мода** — прозрачный BC3/BC7 store-иконки вместо непрозрачного BC1 modIcon.
- **Путь без расширения** или неверный путь относительно корня.
- **Мип-мапы включены** — гайдлайны требуют без мип-мапов.

---

## 10. Примечания

- `<iconFilename>` задаёт иконку **мода**; иконки товаров в магазине указываются отдельно в их store-описании.
- Значение — обычный относительный путь; движок читает любой корректный путь с расширением.
- Формат (512×512, DDS, BC1, без мипов) — требование гайдлайнов ModHub для публикации.

## Глоссарий

[^string]: STRING — строковый тип значения (здесь — путь к файлу). <https://en.wikipedia.org/wiki/String_(computer_science)>
[^xsd]: XSD (XML Schema Definition) — официальная `modDesc.xsd` задаёт обязательность и типы элементов. <https://en.wikipedia.org/wiki/XML_Schema_(W3C)>
[^dds]: DDS (DirectDraw Surface) — формат текстур с аппаратным сжатием, используемый движком. <https://en.wikipedia.org/wiki/DirectDraw_Surface>
[^bcn]: BC1/BC3/BC7 (Block Compression, ранее DXT1/DXT5) — форматы сжатия текстур; BC1 без альфы, BC3/BC7 с альфой. <https://en.wikipedia.org/wiki/S3_Texture_Compression>
[^mipmaps]: Мип-мапы — уменьшенные копии текстуры для разных расстояний; для иконок не используются. <https://en.wikipedia.org/wiki/Mipmap>

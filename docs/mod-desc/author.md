# Farming Simulator 2025
## Элемент `<author>` и указание соавторов

```xml
<author>deliciousNesquik</author>
```

Дочерний элемент `<modDesc>` с именем автора мода. Показывается как «Автор» в информации о моде.
Отдельного стандартного элемента для соавторов в FS25 нет (см. раздел 4).

> Расположение: дочерний элемент `<modDesc>`. Раздел справочника — modDesc.

---

## 1. Что это

`<author>` содержит имя (ник) автора, название команды или перечень авторов. Обязательный
элемент: без него мод не проходит проверку. Значение выводится игрой в деталях мода на экране
информации.

---

## 2. Характеристики

| Свойство | Значение |
|---|---|
| Тип содержимого | STRING[^string] — простая строка, без ограничения длины и без шаблонов. |
| Обязателен | да (`minOccurs="1"` в официальной схеме[^xsd]). |
| Кратность | один: несколько тегов `<author>` недопустимо. |
| Атрибуты | нет. |
| CDATA[^cdata] | допустимо (используется, когда в имени есть спецсимволы). |

---

## 3. Что показывает и где

Значение `<author>` отображается как «Автор» в карточке/деталях мода (меню модов, экран
информации). Это единственное поле авторства, которое движок читает и показывает игроку.

---

## 4. Соавторы — отдельного элемента нет

В схеме `modDesc.xml` FS25 **нет** элементов `<contributors>`, `<contributor>` или иного
стандартного тега для соавторов. Проверено по официальной схеме GIANTS: среди всех дочерних
элементов `<modDesc>` тега соавторов не существует.

Что из этого следует:
- Произвольный `<contributors>`, дописанный в `modDesc.xml`, **движок игнорирует** — он нигде не
  показывается и ни на что не влияет.
- При публикации на ModHub файл проверяется по этой же схеме, и незнакомый элемент может
  вызвать ошибку валидации.

Почему в старых модах встречается `<contributors>`, и мод при этом грузится:
игра **не** проверяет `modDesc.xml` по схеме при загрузке и читает его по фиксированным путям
(`author`, `version`, `title`, ...). Неизвестный элемент движок просто не запрашивает — он молча
игнорируется, поэтому загрузка не ломается. Но его содержимое нигде не читается и не
показывается: экрана соавторов в игре нет ни в одной версии, авторство берётся только из
`<author>`. То есть такой тег — лишь заметка в файле для людей, а не рабочее поле.

Как указывать соавторов правильно:

1. **Перечислением внутри одного `<author>`.** Схема это допускает (документация в ней прямо
   говорит «Author(s) of the mod»). Имена — через запятую или слэш; либо название команды.
2. **В `<description>`, в разделе Credits.** Подробная роспись ролей (модели, скрипты, перевод,
   тестирование) выносится в описание — оно многоязычное и показывается на странице мода.

---

## 5. Примеры

Один автор:

```xml
<author>deliciousNesquik</author>
```

Команда:

```xml
<author>AutoDrive Team</author>
```

Несколько авторов в одном поле (увидят игроки в меню):

```xml
<author>Имя1, Имя2, Имя3</author>
```

Имя со спецсимволами через CDATA:

```xml
<author><![CDATA[Courseplay.devTeam]]></author>
```

Подробные благодарности — в описании, а не отдельным тегом:

```xml
<author>deliciousNesquik</author>
<description>
    <en><![CDATA[...

Credits:
- Models: ...
- Script: ...
- Translation: ...
]]></en>
</description>
```

---

## 6. Типичные ошибки

- **Несколько тегов `<author>`** — недопустимо (элемент одиночный); авторов перечисляют внутри одного.
- **Расчёт на несуществующий `<contributors>`** — движок его не читает, ModHub-валидатор может отклонить.
- **Отсутствие `<author>`** — обязательный элемент, без него мод не пройдёт проверку.

---

## 7. Примечания

- Единственное поле авторства, читаемое движком, — `<author>`. Соавторство схемой не формализовано.
- Официальная схема мододескриптора: `validation.gdn.giants-software.com/xml/fs25/modDesc.xsd` —
  авторитетный источник по составу и обязательности элементов `modDesc.xml`.

# Farming Simulator 2025
## Элемент `<title>`

```xml
<title>
    <en>Title on English</en>
    <ru>Название на русском</ru>
    <de>Titel auf Deutsch</de>
</title>
```

Многоязычное название мода. Показывается в магазине и меню модов на языке игрока. Дочерние
элементы — **языковые коды из фиксированного набора** (не произвольные, см. раздел 3).

> Расположение: дочерний элемент `<modDesc>`. Раздел справочника — modDesc.

---

## 1. Что это

`<title>` задаёт отображаемое имя мода отдельно для каждого языка. Игра берёт вариант,
соответствующий текущему языку игры; если его нет — используется английский (см. раздел 4).

---

## 2. Характеристики

| Свойство | Значение |
|---|---|
| Обязателен | нет по схеме (`minOccurs="0"`), но практически нужен — без него у мода нет имени. |
| Кратность | один тег `<title>` (`maxOccurs="1"`). |
| Дочерние элементы | языковые коды (`<en>`, `<ru>`, `<de>`, …), каждый — строка[^string]. |
| Набор языков | закрытый: ровно 27 кодов (см. раздел 3), не произвольные теги. |
| `<en>` обязателен? | схемой — нет; фактически нужен как язык по умолчанию. |
| Атрибуты | нет. |

---

## 3. Языковые коды (закрытый набор)

Дочерние теги `<title>` — это языковые коды. Схема перечисляет **ровно 27** допустимых кодов
(контейнер `xs:all` с явным списком, без `xs:any`). Тег вне набора делает файл невалидным.

| Код | Язык | Код | Язык |
|---|---|---|---|
| `en` | английский | `pl` | польский |
| `de` | немецкий | `cz` | чешский |
| `fr` | французский | `hu` | венгерский |
| `fc` | французский (Канада) | `ro` | румынский |
| `es` | испанский (Испания) | `ru` | русский |
| `ea` | испанский (Лат. Америка) | `uk` | украинский |
| `it` | итальянский | `tr` | турецкий |
| `pt` | португальский (Португалия) | `da` | датский |
| `br` | португальский (Бразилия) | `no` | норвежский |
| `nl` | нидерландский | `sv` | шведский |
| `fi` | финский | `jp` | японский |
| `id` | индонезийский | `kr` | корейский |
| `vi` | вьетнамский | `cs` | китайский (упрощённый) |
| | | `ct` | китайский (традиционный) |

Сама XSD названия языков не приводит (только пометку «localized title»), поэтому соответствие
код → язык дано по конвенции GIANTS. Особо неоднозначные коды: `cs` — китайский упрощённый,
`ct` — китайский традиционный, `cz` — чешский, `ea` — испанский Латинской Америки, `fc` —
французский канадский. Их легко перепутать; сторонние списки иногда маркируют `cs`/`ct` иначе.

> Тега «любой язык» не существует. Украинский — код `uk` (не `ua`), русский — `ru` и т.д.
> Неподдерживаемый код (например `<zh>`, `<ua>`) невалиден по схеме: валидатор ModHub его
> отклонит, а движок в игре просто проигнорирует.

---

## 4. Какой язык показывается (фолбэк)

- Игра берёт под-элемент, соответствующий текущему языку интерфейса.
- Если для текущего языка тега нет — фолбэк на **`<en>`**.
- Если нет ни текущего языка, ни `<en>` — гарантированного результата нет: имя может оказаться
  пустым или замениться заглушкой. Поэтому `<en>` стоит указывать всегда, даже если основной
  язык другой.

(Логика выбора языка — поведение движка локализации GIANTS; в схеме она не описана.)

---

## 5. Примеры

Три языка:

```xml
<title>
    <en>Spill On Rollover</en>
    <ru>Высыпание груза при опрокидывании</ru>
    <de>Ladung kippt beim Überschlag</de>
</title>
```

Только английский (сработает как фолбэк для всех языков):

```xml
<title>
    <en>Spill On Rollover</en>
</title>
```

Русский без английского — рискованно (для не-русского языка имя может пропасть):

```xml
<title>
    <ru>Высыпание груза при опрокидывании</ru>
</title>
```

---

## 6. `<title>` и `<description>`

`<description>` (описание мода) использует **такую же** структуру: тот же закрытый набор из 27
языковых кодов, каждый — строка. Отличие только в назначении (короткое имя против полного
описания) и в объёме текста (в описании обычно CDATA[^cdata] с переносами).

---

## 7. Типичные ошибки

- **Произвольный/неподдерживаемый код** (`<ua>`, `<zh>`, `<any>`): невалидно по схеме, отклоняется
  валидатором ModHub, движком игнорируется.
- **Нет `<en>`**: для языков, которых нет в `<title>`, имя не отобразится (нет фолбэка).
- **Несколько тегов `<title>`**: допускается только один.
- Ожидание, что можно вписать «любой язык» — нет, только 27 кодов из набора.

---

## 8. Примечания

- По схеме `<title>` необязателен, но мод без названия непрактичен — указывать стоит всегда.
- Набор языков — закрытый список из 27 кодов; расширить его на стороне мода нельзя.
- Соответствие кодов языкам — по конвенции GIANTS, в самой XSD названий нет.

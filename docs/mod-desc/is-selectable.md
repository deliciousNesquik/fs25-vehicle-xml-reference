# Farming Simulator 2025
## Элемент `<isSelectable>`

```xml
<isSelectable>false</isSelectable>
```

Показывать ли мод в экране выбора модов и давать ли игроку включать/выключать его вручную. По
умолчанию `true`. Значение `false` скрывает мод из списка — его используют для вспомогательных
модов и модов-зависимостей.

> Расположение: дочерний элемент `<modDesc>`. Раздел справочника — modDesc.

---

## 1. Что это

`<isSelectable>` управляет видимостью мода в экране выбора модов (там, где игрок отмечает моды для
сохранения/сессии). Обычные моды видимы и выбираемы; служебные — скрывают.

---

## 2. Характеристики

| Свойство | Значение |
|---|---|
| Тип | BOOL[^bool] — элемент с текстом `true`/`false` (не атрибут). |
| Обязателен | нет (`minOccurs="0"`). |
| По умолчанию | `true` (если элемент опущен — мод выбираемый). |
| Атрибуты | нет. |

---

## 3. Что делает

- **`true`** (или элемент отсутствует) — мод **виден** в экране выбора модов, игрок может включать/выключать его.
- **`false`** — мод **скрыт** из списка: вручную выбрать/снять его нельзя.

---

## 4. `false` не значит «не загружается»

Важный нюанс: значение флага влияет **только на видимость строки** в списке. Мод в любом случае
**регистрируется** движком. В игровую сессию он попадёт, если его затребует как зависимость другой,
выбранный мод (см. [dependencies](dependencies.md)): при разрешении зависимостей движок активирует
такой мод автоматически, даже если он не показан в списке.

Если же скрытый мод никем не затребован и не выбран — он остаётся зарегистрированным, но в сессию
не грузится (его логика не активируется).

---

## 5. Типичное применение

- Моды-библиотеки и общие скрипт-модули, которые не должны включаться игроком вручную.
- Моды-зависимости, подтягиваемые по `<dependencies>` других модов.
- Служебные/вспомогательные моды.

Для обычного мода (техника, фичи) элемент не нужен — по умолчанию мод и так выбираемый.

---

## 6. Примеры

Скрыть вспомогательный мод из списка:

```xml
<isSelectable>false</isSelectable>
```

Явно оставить выбираемым (эквивалент отсутствия элемента):

```xml
<isSelectable>true</isSelectable>
```

---

## 7. Типичные ошибки

- **Считать, что `false` полностью отключает мод** — нет, мод регистрируется и грузится, если он
  затребован как зависимость.
- **Ожидать, что скрытый мод загрузится сам по себе** — без выбора и без запроса зависимостью он в
  сессию не попадёт.
- **`1`/`0` вместо `true`/`false`** — тип строго `true`/`false`.

---

## 8. Примечания

- По умолчанию мод выбираемый; элемент нужен в основном для служебных/зависимых модов.
- Флаг меняет только видимость в списке, не факт регистрации.
- Поведение подтверждено по загрузчику модов FS22 (движок общий с FS25; открытого зеркала
  загрузчика FS25 нет).

# Farming Simulator 2025
## Элемент `<dependencies>`

```xml
<dependencies>
    <dependency>FS25_SomeOtherMod</dependency>
</dependencies>
```

Список других модов, которые **тоже должны быть включены**, чтобы этот мод работал. Это проверка
требований (включён ли нужный мод), а **не** управление порядком загрузки (см. раздел 5).

> Расположение: дочерний элемент `<modDesc>`. Раздел справочника — modDesc.

---

## 1. Что это

`<dependencies>` перечисляет моды, от которых зависит текущий. Каждый `<dependency>` называет один
требуемый мод. Если в наборе модов сессии его нет, игра не даёт стартовать, пока зависимость не
будет включена/установлена (раздел 6).

---

## 2. Содержимое `<dependency>`

| Что | Значение |
|---|---|
| Содержимое | текст[^string] — имя файла требуемого мода **без `.zip`** (= имя папки мода). |
| Кратность | несколько `<dependency>` допустимо. |
| Атрибуты | нет. |

`<dependencies>` необязателен (`minOccurs="0"`), один. Документация схемы: «filename of the mod
(without '.zip') to be installed for this mod to be used».

---

## 3. Формат значения

- Значение — базовое имя мода: для `FS25_SomeMod.zip` пишется `FS25_SomeMod` (то же, что имя папки
  при распаковке).
- Сопоставление **точное и регистрозависимое** (движок ищет по ключу таблицы модов). `fs25_somemod`
  или лишние пробелы не совпадут.
- Расширение `.zip` не указывается.

---

## 4. Что делает

При старте сессии (экран выбора модов) для каждого выбранного мода игра проверяет, включены ли его
зависимости. Если требуемый мод не активен — старт блокируется, пока это не разрешат (раздел 6).
То есть `<dependency>` гарантирует **наличие/включённость** нужного мода.

---

## 5. Не управляет порядком загрузки

Распространённое заблуждение: `<dependency>` **не** заставляет требуемый мод загрузиться раньше.
Движок не сортирует загрузку по зависимостям — моды регистрируются в порядке файловой системы, а в
меню сортируются по алфавиту заголовка. Если код одного мода должен инициализироваться раньше кода
другого, `<dependency>` этого не обеспечивает — он лишь требует, чтобы нужный мод тоже был включён.

---

## 6. Отсутствующая зависимость

Если требуемый мод не активен, поведение при старте:

- **Одиночная игра:**
    - установлен, но не включён → диалог «требуются моды, включить все?» (при согласии включает);
    - не установлен, но есть на ModHub → диалог «скачать требуемые?» → установка с ModHub;
    - нигде не найден → информационный диалог со списком, старт заблокирован.
- **Выделенный сервер:** интерактивного диалога нет — в лог пишется ошибка вида
  `Could not start dedicated server ... because some dependencies are missing: '<Мод>' wants '<Зависимость>.zip'`,
  сессия не стартует.

То есть мод не «тихо грузится без зависимости» и не отключается молча — игра требует разрешить
зависимость до запуска.

---

## 7. Мультиплеер

На выделенном сервере наличие зависимостей проверяется жёстко (ошибка в лог, старт заблокирован).
В остальном мод-зависимость — обычный мод: он должен присутствовать у всех участников и
раздаётся/синхронизируется клиентам по стандартным правилам MP. Отдельного сетевого механизма
`<dependency>` не добавляет.

---

## 8. ModHub

Гайдлайны ModHub требуют: если мод зависит от другого — прописать зависимости в `modDesc.xml` и
указать это в комментарии к заявке. Автоматическое скачивание зависимости работает только если она
сама есть на ModHub (у неё есть внутренний идентификатор); зависимость не с ModHub игра сможет лишь
показать как недоступную.

---

## 9. Примеры

Одна зависимость:

```xml
<dependencies>
    <dependency>FS25_UniversalAutoload</dependency>
</dependencies>
```

Несколько:

```xml
<dependencies>
    <dependency>FS25_Courseplay</dependency>
    <dependency>FS25_AutoDrive</dependency>
</dependencies>
```

---

## 10. Типичные ошибки

- **Неверное имя/регистр** — совпадение точное; `FS25_SomeMod` ≠ `fs25_somemod`.
- **Указано с `.zip`** — расширение не пишется.
- **Ожидание управления порядком загрузки** — `<dependency>` этого не делает (раздел 5).
- **Расчёт на авто-скачивание зависимости не с ModHub** — авто-резолв только для ModHub-модов.

---

## 11. Примечания

- Назначение — гарантировать, что требуемый мод тоже включён, а не когда он грузится.
- Значение — имя файла/папки мода без `.zip`, точное совпадение.
- Механика проверки подтверждена по загрузчику модов FS22 (движок общий с FS25; открытого зеркала
  загрузчика FS25 нет).

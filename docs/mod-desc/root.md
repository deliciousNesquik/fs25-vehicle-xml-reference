# Farming Simulator 2025
## Корневой тег `<modDesc>` — атрибуты

```xml
<modDesc descVersion="98">
    ...
</modDesc>
```

Корневой элемент файла `modDesc.xml` — «паспорта» мода. На этой странице — только **атрибуты
самого корня** `<modDesc>`. Дочерние элементы (`author`, `version`, `title`, `description`,
`iconFilename`, `multiplayer`, `l10n` и т.д.) — отдельные темы раздела modDesc.

> Расположение: корневой элемент `modDesc.xml`. Раздел справочника — modDesc.

---

## 1. Что это

`<modDesc>` оборачивает всё описание мода. У самого тега движок читает **ровно один** атрибут —
`descVersion`, задающий версию формата `modDesc.xml`. По нему игра решает, совместим ли мод с
текущей версией движка.

---

## 2. Атрибуты корня

| Атрибут | Тип | Обязателен | Значение (FS25) | Описание |
|---|---|---|---|---|
| `descVersion` | INT[^int] | да | см. таблицу ниже | Версия формата `modDesc.xml`. Проверяется на диапазон, поддерживаемый движком. |
| `xmlns:xsi` | STRING | нет | `http://www.w3.org/2001/XMLSchema-instance` | Объявление пространства имён[^namespace] XSD. Движком **не читается** — подсказка для валидации в редакторе. |
| `xsi:noNamespaceSchemaLocation` | STRING | нет | путь к `.xsd` | Ссылка на XSD-схему[^xsd] для валидации. Движком **не читается**. |

Реально на загрузку мода влияет только `descVersion`. Два `xsi`-атрибута встречаются в корне
некоторых модов как вспомогательные метки для проверки по XSD в редакторе и на игру не влияют.

---

## 3. Атрибут `descVersion`

Целое число — версия структуры `modDesc.xml`. Игра сверяет его с внутренними границами
поддерживаемых версий (нижней и верхней). Логика:

- **Атрибут отсутствует** — мод отбраковывается с ошибкой вида `Missing descVersion attribute in mod <name>`.
- **Значение вне диапазона** (слишком старое или слишком новое для этой версии игры) — мод не
  загружается с ошибкой `Unsupported mod description version in mod <name>`.
- **Значение в пределах диапазона** — мод принимается.

Важное свойство FS25: верхняя граница поддерживаемого `descVersion` **не постоянна** — она
поднимается почти с каждым обновлением игры. Поэтому «единственно верного» значения нет: есть
значение, подходящее целевому патчу.

---

## 4. Значения `descVersion` по версиям игры

| Игра | `descVersion` | Примечание |
|---|---|---|
| FS19 | ≈ 40–53 | приблизительно (по реальным модам) |
| FS22 | 60–80 (нижняя–верхняя) | стабильно весь цикл игры |
| FS25 | нижняя ≈ 90; верхняя растёт по патчам | примеры из живых модов: 97, 98, 105, 106, 107, ~110 |

Ключевое отличие FS25 от FS22: в FS22 верхняя граница держалась на `80` весь цикл, а в FS25 она
повышается почти каждым патчем. Значения в таблице FS25 — ориентир по вышедшим модам, а не
фиксированные константы.

---

## 5. Как выбрать значение

- Ставить `descVersion` **в пределах диапазона целевого патча** игры. Обычно это актуальное на
  момент выпуска мода значение (у большинства свежих модов — из верхней части диапазона).
- **Слишком новое** (больше верхней границы патча) — мод не загрузится (`Unsupported mod
  description version`); лечится понижением до значения, которое принимает текущий патч.
- **Слишком старое** (меньше нижней границы) — мод тоже отбраковывается как устаревший.
- Значение с прошлой части серии (например `80` из FS22) в FS25 **не подойдёт** — оно ниже
  нижней границы FS25.

Точную верхнюю границу конкретной установки можно посмотреть только в распакованных скриптах
игры (строка `g_maxModDescVersion` в `scripts/main.lua`); в открытых зеркалах исходников
загрузчика нет, поэтому таблица выше опирается на значения вышедших модов.

---

## 6. Примеры

Типовой корень мода FS25:

```xml
<?xml version="1.0" encoding="utf-8" standalone="no"?>
<modDesc descVersion="98">
    <author>...</author>
    <version>...</version>
    <!-- дочерние элементы -->
</modDesc>
```

С необязательными `xsi`-метками для валидации в редакторе (движком игнорируются):

```xml
<modDesc descVersion="98"
         xmlns:xsi="http://www.w3.org/2001/XMLSchema-instance"
         xsi:noNamespaceSchemaLocation="modDesc.xsd">
    ...
</modDesc>
```

---

## 7. Типичные ошибки

- **Нет `descVersion`** — мод не грузится (`Missing descVersion attribute`).
- **Значение от прошлой игры** (например `80` из FS22) — ниже нижней границы FS25, отбраковка.
- **Слишком высокое значение** «на вырост» — выше верхней границы текущего патча, отбраковка
  (`Unsupported mod description version`).
- Ожидание, что `xmlns:xsi` / `xsi:noNamespaceSchemaLocation` что-то дают в игре — нет, движок их
  не читает.

---

## 8. Примечания

- У корня `<modDesc>` движок читает только `descVersion`; всё прочее — дочерние элементы (отдельные страницы).
- Верхняя граница `descVersion` в FS25 привязана к версии игры и растёт с патчами.
- Поведение отбраковки (пропуск мода при отсутствии/несовместимости `descVersion`) неизменно на
  протяжении серии игр.

## Глоссарий

[^int]: INT — целочисленный тип значения. <https://en.wikipedia.org/wiki/Integer>
[^namespace]: Пространство имён XML — механизм, разделяющий имена из разных словарей в одном документе. <https://en.wikipedia.org/wiki/XML_namespace>
[^xsd]: XSD (XML Schema Definition) — язык описания структуры и типов XML-документа для валидации. <https://en.wikipedia.org/wiki/XML_Schema_(W3C)>

# Farming Simulator 2025
## Элемент `<helpLines>`

```xml
<helpLines>
    <category title="$l10n_help_cat_overview">
        <page title="$l10n_help_p1_title" iconSliceId="icon_info">
            <paragraph>
                <title text="$l10n_help_p1_what_title"/>
                <text  text="$l10n_help_p1_what_text"/>
            </paragraph>
        </page>
    </category>
</helpLines>
```

Добавляет **страницы помощи** мода — обучающий контент во вкладке «Помощь» игрового меню (Esc/пауза).
Структура: категории → страницы → абзацы (заголовок + текст + картинка). Контент мода **дополняет**
базовую помощь, не заменяет её.

> Расположение: дочерний элемент `<modDesc>`. Раздел справочника — modDesc.

---

## 1. Что это

Во вкладке «Помощь» игрового меню собраны справочные страницы. `<helpLines>` позволяет моду добавить
свои: каждая `<category>` — раздел списка, каждая `<page>` — пункт, каждый `<paragraph>` — блок
(заголовок/текст/изображение). Категории мода **добавляются в конец** базовых.

Важная деталь: помощь мода видна **только после загрузки карты** (категории вливаются в общий список при
старте миссии), в главном меню её нет.

---

## 2. Как загружается

- modDesc читает `modDesc.helpLines.category` и для каждой категории вызывает
  `g_helpLineManager:addModCategory(...)` с окружением мода и его директорией.
- Читается у **всех** модов (не только DLC).
- Категории мода **дополняют** базовые: сначала идут базовые/карты, затем — категории модов (в порядке
  загрузки модов). Замены нет.

---

## 3. Структура

```
<helpLines>
    <category title="...">
        <page title="..." iconSliceId="...">
            <paragraph noSpacing="...">
                <title text="..."/>
                <text  text="..." alignToImage="..."/>
                <image filename="..." .../>
            </paragraph>
        </page>
    </category>
</helpLines>
```

Каждый `<paragraph>` может содержать `<title>`, `<text>` и `<image>` (все необязательны, в любом
сочетании).

---

## 4. `<category>`

| Атрибут | Тип | Описание |
|---|---|---|
| `title` | L10N[^l10n] | Заголовок раздела в списке помощи. |
| `id` | STRING[^string] | Необязательный идентификатор. У мода неймспейсится (`<modName>.<id>`); вторичный ключ (для триггеров помощи на карте), не для отображения. |

Порядок категорий определяется их позицией в списке.

---

## 5. `<page>`

| Атрибут | Тип | Описание |
|---|---|---|
| `title` | L10N | Заголовок страницы (в FS22 это же — её идентификатор; страницы адресуются по позиции). |
| `id` | STRING | Стабильный идентификатор страницы. |
| `iconFilename` | STRING | Свой файл иконки страницы (путь от корня мода). |
| `iconSliceId` | STRING | Имя слайса из UI-атласа игры как встроенная иконка (например `icon_info`). |

`title` в FS22 — единственный читаемый атрибут страницы; `id`/`iconFilename`/`iconSliceId` добавлены в
схему FS25 (парсер FS25 в открытые исходники не входит — семантика по XSD и реальным модам).

---

## 6. `<paragraph>`, `<title>`, `<text>`

| Элемент/атрибут | Тип | Описание |
|---|---|---|
| `<paragraph noSpacing>` | BOOL[^bool] | `true` — убрать вертикальный отступ абзаца (примкнёт к предыдущему). |
| `<title text>` | L10N | Заголовок абзаца. |
| `<text text>` | L10N | Текст абзаца. |
| `<text alignToImage>` | BOOL | `true` (при наличии картинки и текста) — выровнять текст по высоте картинки и центрировать по вертикали. |

---

## 7. `<image>`

Отдельный файл изображения (не слайс общего атласа).

| Атрибут | Тип | По умолчанию | Описание |
|---|---|---|---|
| `filename` | STRING | — | Путь к текстуре, относительно корня мода. |
| `size` | VEC2 | `1024 1024` | Исходное разрешение текстуры — опорное для нормализации `uvs` в пикселях (не экранный размер). |
| `uvs` | STRING LIST | `0 0 1 1` | Под-прямоугольник (спрайт) внутри текстуры: `x y w h`. Доли `0..1`, либо суффикс `px` (делится на `size`), либо `dp`. Позволяет паковать несколько картинок в одну текстуру. |
| `displaySize` | STRING | — | Явный экранный размер `[ш в]` относительно опорного экрана (доли/`px`/`dp`). Если задан — используется напрямую. |
| `aspectRatio` | FLOAT[^float] | `1` | Используется только когда нет `displaySize` и нет текста: картинка на всю ширину строки, высота = ширина × `aspectRatio` × экранное соотношение. Авторы задают как высота/ширина кропа. |
| `heightScale` | FLOAT | `1` | Считывается, но в FS22 не используется (зарезервировано). |

---

## 8. Локализация

`title`/`text` — ключи локализации. Переводится **только** строка с префиксом `$l10n_`: движок
отрезает `$l10n_` и берёт текст по ключу из локализации **самого мода** (с откатом на базовую игру).
Строка без `$l10n_` показывается **как есть** (частая тихая ошибка). Подставляется `$CURRENCY_SYMBOL`.

- Нет ключа в локализации → в меню видно `Missing '<key>' in l10n_<lang>.xml`.
- Забыт префикс `$l10n_` → показан сырой ключ (без ошибки).

## 9. Примеры

Текстовая страница (реальный мод FS25_IncomeMod, инлайн в modDesc):

```xml
<helpLines>
    <category title="$l10n_im_help_cat_overview">
        <page title="$l10n_im_help_p1_title" iconSliceId="icon_info">
            <paragraph>
                <title text="$l10n_im_help_p1_what_title"/>
                <text  text="$l10n_im_help_p1_what_text"/>
            </paragraph>
            <paragraph>
                <title text="$l10n_im_help_p1_mp_title"/>
                <text  text="$l10n_im_help_p1_mp_text"/>
            </paragraph>
        </page>
    </category>
</helpLines>
```

Абзац с картинкой (кроп через `uvs`, той же схемы; из Courseplay):

```xml
<paragraph>
    <text text="$l10n_CP_help_page_startJobMenuBase_text"/>
    <image filename="img/helpmenu/startjobmenuhelp.dds" size="1024 1024" uvs="0px 0px 1024px 895px" aspectRatio="0.87"/>
</paragraph>
```

## 10. Типичные ошибки

- **Забыт префикс `$l10n_`** у `title`/`text` — показан сырой ключ, без ошибки.
- **Нет ключа в локализации мода** — в меню строка `Missing '…' in l10n_…xml`.
- **Ожидание, что помощь видна в главном меню** — нет: только после загрузки карты.
- **`size` как экранный размер** — это опорное разрешение текстуры для `uvs`; экранный размер задаёт
  `displaySize`/`aspectRatio`.
- **Неверный `uvs`** — предупреждение, UV не применяются.
- **Неверный `filename` картинки** — проверки нет; будет пустая/битая текстура.

---

## 11. Примечания

- Контент мода дополняет базовую помощь и всегда идёт после базовых категорий; порядок между модами —
  порядок их загрузки.
- Категория = раздел списка, страница = пункт; выбор страницы рендерит её абзацы.
- `title`/`text` — `$l10n_`-ключи из локализации мода; строки без префикса — буквальные.
- `<image>` — отдельный файл; `uvs` вырезает область, `size` — опорное разрешение, `displaySize`/`aspectRatio`
  задают экранный размер; `heightScale` в FS22 не используется.
- Механика подтверждена по исходникам FS22 (`misc/HelpLineManager.lua`, `gui/InGameMenuHelpFrame.lua`,
  `mods.lua`) и реальными модами (FS25_IncomeMod, Courseplay_FS25). Парсер FS25 в открытые исходники не
  входит (byte-identical FS22 в зеркалах); атрибуты страницы `id`/`iconFilename`/`iconSliceId` — из
  схемы FS25, семантика по XSD и реальным модам.
